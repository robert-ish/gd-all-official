# gd-all-official
A geometry dash list of ALL official-ish levels. And i mean ALL OF THEM.
This includes, all robtop levels, map packs, gauntlets, even the geometrydash.com level.
## How to get
If you dont have Geode installed, [install geode](https://geode-sdk.org/install)  
Get the mod [GDShare](https://geode-sdk.org/mods/hjfod.gdshare), download the [list file](All-official-ish-levels.gmdl), and import the list file.  
It may lag, it probably will lag.
